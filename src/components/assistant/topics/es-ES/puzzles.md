Para empezar a resolver puzles, abre [[page:new-tab]] y haz clic en {{label:Home.Card.Puzzle.Title}}.

Cuando el entrenamiento de ChessRiddle esté disponible, puedes cambiar entre {{label:Puzzle.Source.ChessRiddle}} y {{label:Puzzle.Source.Offline}} con el selector de fuente en la parte superior del panel de puzles (o hacer clic en {{label:Puzzle.Source.UseOffline}} para ir directamente a los puzles sin conexión).

**{{label:Puzzle.Source.ChessRiddle}}** requiere una cuenta conectada de ChessRiddle (puedes conectarla directamente desde el panel de puzles o en [[page:accounts]]):
- Cambia entre {{label:Training.Tactics}} y {{label:Training.Mistakes}} para practicar táctica general o repasar puzles fallados.
- Introduce las jugadas para ambos bandos en el tablero y envía tu línea.
- Haz clic en {{label:Training.Settings.Title}} para elegir {{label:Training.Settings.Difficulty}}, {{label:Training.Settings.Motif}}, {{label:Training.Settings.ShowSolutionLength}}, {{label:Training.Settings.ShowTimer}} y {{label:Training.Settings.TimerMode}}.
- Haz clic en {{label:Training.Shortcuts.Title}} (o pulsa `?`) para ver los atajos de teclado de entrenamiento.

**{{label:Puzzle.Source.Offline}}** utiliza bases de datos locales guardadas en [[setting:puzzles-directory]]:
- Abre el desplegable de bases de datos y elige {{label:Common.AddNew}} para descargar una base de datos de puzles del catálogo o haz clic en {{label:Puzzle.ChooseLocalFolder}} para seleccionar una carpeta local.
- Haz clic en {{label:SideBar.Settings}} (el icono del engranaje) para definir {{label:Puzzle.RatingRange}}, filtrar por {{label:Puzzle.Theme}} y activar o desactivar {{label:Puzzle.Progressive}}, {{label:Puzzle.HideRating}}, {{label:Puzzle.JumpToNextPuzzleImmediately}} y {{label:Puzzle.TrackPuzzleTime}}.
- Elimina la base de datos de puzles seleccionada con {{label:Puzzle.DeleteDatabase}}.
