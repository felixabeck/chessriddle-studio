상단 탐색 줄에는 애플리케이션 메뉴, 고정된 [[page:library]] ({{label:SideBar.Library}}) 링크, 열려 있는 페이지 탭([[page:accounts]], [[page:engines]], [[page:settings]]), 보드 탭, 그리고 {{label:Navigation.Feedback}} 및 {{label:Navigation.Assistant}} 버튼이 있습니다.

새 탭을 열려면 탭 표시줄에서 {{label:Tab.NewTab}}(더하기 버튼)을 클릭하거나, {{label:Menu.File}} -> {{label:Menu.File.NewTab}}을 사용하거나, {{label:Settings.Keybinds.Actions.NEW_TAB}} 단축키를 누르세요. [[page:new-tab]] 페이지로 바로 이동할 수도 있습니다.

[[page:new-tab]]에서 작업 버튼을 누르면 현재 탭에서 작업이 시작됩니다:
- {{label:Home.Card.PlayChess.Button}}: 엔진 또는 다른 사람과 대국합니다.
- {{label:Home.Card.AnalysisBoard.Title}}: 빈 분석 보드를 엽니다.
- {{label:Home.Card.Puzzle.Title}}: 퍼즐 훈련을 엽니다.
- {{label:Home.Card.NewRepertoire.Title}}: 새 오프닝 레퍼토리 파일을 만듭니다.
- {{label:Home.Card.ImportGame.Button}}: PGN 파일, 붙여넣은 PGN, 온라인 대국 링크 또는 FEN 포지션을 불러옵니다.

작업 버튼 아래의 [[page:new-tab]]에는 라이브러리와 최근 대국이 표시됩니다. {{label:Home.Library.Search}} 상자와 {{label:Home.Library.All}}, {{label:Home.Library.Repertoires}}, {{label:Home.Library.Games}}, {{label:Home.Library.Due}} 필터를 사용해 항목을 찾거나, {{label:Home.Library.OpenLibrary}}을(를) 클릭해 [[page:library]]로 이동하세요.

탭 표시줄에서 보드 탭을 관리할 수 있습니다:
- 탭을 드래그하여 순서를 바꿉니다.
- 탭을 마우스 오른쪽 버튼으로 클릭(또는 포커스된 탭에서 Shift+F10 입력)하여 {{label:Tab.Duplicate}}, {{label:Tab.Rename}} 또는 {{label:Tab.Close}}을(를) 선택합니다. 포커스된 탭에서 F2 키를 눌러 이름을 바꿀 수도 있습니다.
- 탭이 많이 열려 있을 때는 {{label:Tab.AllTabs}}을(를) 클릭해 목록에서 원하는 탭을 선택하세요.
- 페이지 탭([[page:accounts]], [[page:engines]], [[page:settings]])은 닫기 버튼을 눌러 닫습니다.
