퍼즐을 풀려면 [[page:new-tab]]을 열고 {{label:Home.Card.Puzzle.Title}}을(를) 클릭하세요.

ChessRiddle 훈련을 사용할 수 있을 때는 퍼즐 패널 상단의 소스 선택기에서 {{label:Puzzle.Source.ChessRiddle}}와 {{label:Puzzle.Source.Offline}} 사이를 전환하거나, {{label:Puzzle.Source.UseOffline}}을(를) 클릭해 바로 오프라인 퍼즐로 이동할 수 있습니다.

**{{label:Puzzle.Source.ChessRiddle}}**를 사용하려면 연결된 ChessRiddle 계정이 필요합니다(퍼즐 패널에서 직접 연결하거나 [[page:accounts]]에서 연결 가능):
- 일반 전술을 풀거나 놓친 문제를 다시 풀려면 {{label:Training.Tactics}}와 {{label:Training.Mistakes}} 사이를 전환하세요.
- 보드에서 양쪽의 수를 입력한 뒤 해답을 제출합니다.
- {{label:Training.Settings.Title}}을(를) 클릭해 {{label:Training.Settings.Difficulty}}, {{label:Training.Settings.Motif}}, {{label:Training.Settings.ShowSolutionLength}}, {{label:Training.Settings.ShowTimer}}, {{label:Training.Settings.TimerMode}}을(를) 선택하세요.
- 훈련 단축키를 보려면 {{label:Training.Shortcuts.Title}}을(를) 클릭하거나 `?` 키를 누르세요.

**{{label:Puzzle.Source.Offline}}**는 [[setting:puzzles-directory]]에 저장된 로컬 퍼즐 데이터베이스를 사용합니다:
- 데이터베이스 드롭다운을 열고 {{label:Common.AddNew}}을(를) 선택해 카탈로그에서 퍼즐 데이터베이스를 다운로드하거나, {{label:Puzzle.ChooseLocalFolder}}을(를) 클릭해 로컬 폴더를 선택하세요.
- {{label:SideBar.Settings}}(톱니바퀴 아이콘)를 클릭해 {{label:Puzzle.RatingRange}} 설정, {{label:Puzzle.Theme}}별 필터링 및 {{label:Puzzle.Progressive}}, {{label:Puzzle.HideRating}}, {{label:Puzzle.JumpToNextPuzzleImmediately}}, {{label:Puzzle.TrackPuzzleTime}} 옵션을 켜거나 끌 수 있습니다.
- 선택한 퍼즐 데이터베이스를 제거하려면 {{label:Puzzle.DeleteDatabase}}을(를) 사용하세요.
