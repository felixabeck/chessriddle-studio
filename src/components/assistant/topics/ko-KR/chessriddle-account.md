ChessRiddle 계정은 Studio를 {{label:Puzzle.Source.ChessRiddle}} 온라인 퍼즐 훈련에 연결합니다.

연결은 [[page:accounts]] ({{label:SideBar.Accounts}})의 {{label:Home.ChessRiddle.Title}} 카드에서 관리하거나, [[page:new-tab]]에서 {{label:Home.Card.Puzzle.Title}}을(를) 열었을 때 퍼즐 패널에서 바로 관리할 수 있습니다.

- 브라우저를 통해 로그인하려면 {{label:Home.ChessRiddle.Connect}}을(를) 클릭하세요. 세션 자격 증명은 시스템 키링에 저장됩니다.
- 연결되면 카드에 사용자 이름과 플랜(Free 또는 Gold)이 표시됩니다.
- 현재 계정 상태와 플랜을 확인하려면 {{label:Home.ChessRiddle.Refresh}}을(를) 클릭하세요.
- 세션이 만료되면 {{label:Home.ChessRiddle.Reconnect}}을(를) 클릭해 다시 로그인하세요.
- 이 컴퓨터에서 계정을 제거하고 로그아웃하려면 {{label:Home.ChessRiddle.Disconnect}}을(를) 클릭하세요.
- 연결한 후에는 [[page:library]]에서 {{label:Library.Sync.Action}}을(를) 클릭하여 선택한 PGN 파일과 기보 데이터베이스를 비공개 ChessRiddle 라이브러리에 동기화할 수 있습니다(단방향, 웹사이트에서는 읽기 전용).
