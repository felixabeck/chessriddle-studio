Отчёт по партии анализирует каждый ход главной линии с помощью локального шахматного движка и подводит итог по точности и ошибкам.

Чтобы создать отчёт, откройте партию на доске анализа, перейдите на вкладку {{label:Board.Analysis.Report}} и нажмите {{label:Board.Analysis.GenerateReport}} (или горячую клавишу {{label:Settings.Keybinds.Actions.GENERATE_REPORT}}).

В диалоге {{label:Board.Analysis.GenerateReport}}:
- Выберите локальный {{label:Common.Engine}}. Если ни один не установлен, добавьте его на странице [[page:engines]].
- Задайте ограничение поиска на ход (глубина, время или узлы).
- Включите {{label:Board.Analysis.MarkMoves}}, чтобы расставить знаки качества ходов.
- Включите {{label:Board.Analysis.ShowVariations}}, чтобы добавить в нотацию варианты с лучшими ходами.
- Включите {{label:Board.Analysis.AnnotateNovelties}}, чтобы отметить первый ход, выходящий за пределы вашей справочной базы данных. Для этого должна быть выбрана готовая справочная база в [[page:library]].
- Нажмите {{label:Board.Analysis.Analyze}} для запуска.

Пока отчёт выполняется, вы можете отменить его кнопкой прогресса. Редактирование главной линии отменяет текущий расчёт отчёта.

После завершения во вкладке {{label:Board.Analysis.Report}} отображаются:
- Проценты точности и средние потери сантипешек (ACPL) для {{label:Common.WHITE}} и {{label:Common.BLACK}}.
- График оценки на протяжении всей партии.
- {{label:Board.Analysis.Report.KeyMoments}}: интерактивный список отмеченных ходов со скачками оценки и лучшими продолжениями.
- Таблица распределения качества ходов, где нажатие на счётчик переходит к соответствующим ходам.

Если вы отредактировали партию позже, нажмите {{label:Board.Analysis.RegenerateReport}}, чтобы запустить новый анализ.
