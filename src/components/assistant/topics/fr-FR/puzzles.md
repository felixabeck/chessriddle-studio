Pour commencer à résoudre des problèmes, ouvrez [[page:new-tab]] et cliquez sur {{label:Home.Card.Puzzle.Title}}.

Lorsque l’entraînement ChessRiddle est disponible, vous pouvez basculer entre {{label:Puzzle.Source.ChessRiddle}} et {{label:Puzzle.Source.Offline}} à l’aide du sélecteur de source en haut du panneau de problèmes (ou cliquer sur {{label:Puzzle.Source.UseOffline}} pour accéder directement aux problèmes hors ligne).

**{{label:Puzzle.Source.ChessRiddle}}** nécessite un compte ChessRiddle connecté (vous pouvez vous connecter directement depuis le panneau de problèmes ou sur [[page:accounts]]) :
- Basculez entre {{label:Training.Tactics}} et {{label:Training.Mistakes}} pour travailler la tactique générale ou revoir les problèmes manqués.
- Jouez les coups pour les deux camps sur l’échiquier, puis validez votre suite.
- Cliquez sur {{label:Training.Settings.Title}} pour choisir {{label:Training.Settings.Difficulty}}, {{label:Training.Settings.Motif}}, {{label:Training.Settings.ShowSolutionLength}}, {{label:Training.Settings.ShowTimer}} et {{label:Training.Settings.TimerMode}}.
- Cliquez sur {{label:Training.Shortcuts.Title}} (ou appuyez sur `?`) pour afficher les raccourcis clavier d’entraînement.

**{{label:Puzzle.Source.Offline}}** utilise des bases de problèmes locales stockées dans [[setting:puzzles-directory]] :
- Ouvrez le menu déroulant des bases et choisissez {{label:Common.AddNew}} pour télécharger une base de problèmes depuis le catalogue, ou cliquez sur {{label:Puzzle.ChooseLocalFolder}} pour choisir un dossier local.
- Cliquez sur {{label:SideBar.Settings}} (l’icône d’engrenage) pour définir {{label:Puzzle.RatingRange}}, filtrer par {{label:Puzzle.Theme}} et activer ou désactiver {{label:Puzzle.Progressive}}, {{label:Puzzle.HideRating}}, {{label:Puzzle.JumpToNextPuzzleImmediately}} et {{label:Puzzle.TrackPuzzleTime}}.
- Supprimez la base de problèmes sélectionnée avec {{label:Puzzle.DeleteDatabase}}.
