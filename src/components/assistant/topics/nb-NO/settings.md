Åpne [[page:settings]] ({{label:SideBar.Settings}}) fra programmenyen (eller trykk Cmd+, på macOS). Bruk feltet {{label:Common.Search}} øverst i [[page:settings]] for å filtrere alle innstillinger etter tittel, beskrivelse, gruppe eller nøkkelord, og trykk Escape for å tømme søket.

Innstillingene er delt inn i to sidefeltgrupper, Sjakk og App:

Sjakk:
- [[settings-category:board]] ({{label:Settings.Board}}): hvordan brettet ser ut og hvordan du flytter brikker, inkludert [[setting:board-image]], [[setting:board-wood-texture]], [[setting:piece-set]], [[setting:piece-size]], [[setting:coordinates]], [[setting:animation-speed]], [[setting:piece-dest]], [[setting:move-highlight]], [[setting:move-highlight-color]], [[setting:move-highlight-opacity]], [[setting:move-method]], [[setting:text-input]], [[setting:auto-promote]], [[setting:flip-board-after-move]], [[setting:arrows]], [[setting:variation-arrows]], [[setting:snap-arrows]], [[setting:consecutive-arrows]] og [[setting:erase-drawables]].
- [[settings-category:analysis]] ({{label:Settings.Analysis}}): notasjon, navigasjon, panellayout og automatisk lagring via [[setting:move-notation]], [[setting:material-display]], [[setting:scroll-moves]], [[setting:choose-variation]], [[setting:preview-board]], [[setting:default-panel-tab]], [[setting:board-layout]] og [[setting:auto-save]].
- [[settings-category:repertoire]] ({{label:Settings.Repertoire}}): dekningsterskel for repertoar og øvingsplanlegging via [[setting:repertoire-depth]], [[setting:practice-grading]] og [[setting:practice-new-per-session]].
- [[settings-category:coach]] ({{label:Settings.AI}}): administrer KI-tilkoblinger for Coach og Assistant, velg modellen de svarer med i [[setting:coach-model]], og velg Coachens lokale motor i [[setting:coach-engine]].

App:
- [[settings-category:general]] ({{label:Settings.General}}): språk, tema, skriftstørrelse og inndata via [[setting:language]], [[setting:theme]], [[setting:font-size]], {{label:Settings.Appearance.TitleBar}} (på Windows og Linux) og [[setting:spell-check]].
- [[settings-category:sound]] ({{label:Settings.Sound}}): volum for trekklyder og lydpakke via [[setting:volume]] og [[setting:sound-collection]].
- [[settings-category:keybinds]] ({{label:Settings.Keybinds}}): tilpass tastatursnarveier, tilbakestill dem med {{label:Common.Reset}}, og se musemodifikatorene for {{label:Settings.Drawing}}.
- [[settings-category:directories]] ({{label:Settings.Directories}}): konfigurer lagringsmapper via [[setting:files-directory]], [[setting:databases-directory]], [[setting:engines-directory]] og [[setting:puzzles-directory]].
- [[settings-category:advanced]] ({{label:Settings.Advanced}}): vedlikeholdsverktøy inkludert [[setting:reload]], [[setting:clear-saved-data]] og [[setting:open-logs]].
