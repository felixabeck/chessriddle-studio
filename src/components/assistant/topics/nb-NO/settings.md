Åpne [[page:settings]] ({{label:SideBar.Settings}}) fra programmenyen (eller trykk Cmd+, på macOS). Bruk feltet {{label:Common.Search}} øverst i [[page:settings]] for å filtrere alle innstillinger etter tittel, beskrivelse eller nøkkelord, og trykk Escape for å tømme søket.

Innstillingene er ordnet i ni kategorier:
- [[settings-category:board]] ({{label:Settings.Board}}): brettets oppførsel og utforming, inkludert [[setting:piece-dest]], [[setting:move-highlight]], [[setting:move-highlight-color]], [[setting:move-highlight-opacity]], [[setting:arrows]], [[setting:variation-arrows]], [[setting:move-notation]], [[setting:move-method]], [[setting:snap-arrows]], [[setting:consecutive-arrows]], [[setting:erase-drawables]], [[setting:auto-promote]], [[setting:coordinates]], [[setting:animation-speed]], [[setting:auto-save]], [[setting:preview-board]], [[setting:flip-board-after-move]], [[setting:scroll-moves]], [[setting:choose-variation]], [[setting:material-display]], [[setting:default-panel-tab]] og [[setting:panels-beside-notation]].
- [[settings-category:inputs]] ({{label:Settings.Inputs}}): inntasting av trekk og stavekontroll for kommentarer via [[setting:text-input]] og [[setting:spell-check]].
- [[settings-category:appearance]] ({{label:Settings.Appearance}}): visuell tilpasning via [[setting:theme]], [[setting:language]], {{label:Settings.Appearance.TitleBar}} (på Windows og Linux), [[setting:font-size]], [[setting:piece-set]], [[setting:piece-size]], [[setting:board-image]] og [[setting:board-wood-texture]].
- [[settings-category:sound]] ({{label:Settings.Sound}}): lydstyrke for trekk og lydpakke via [[setting:volume]] og [[setting:sound-collection]].
- [[settings-category:keybinds]] ({{label:Settings.Keybinds}}): tilpass tastaturbindinger, tilbakestill dem med {{label:Common.Reset}} og se musmodifikatorene for {{label:Settings.Drawing}}.
- [[settings-category:directories]] ({{label:Settings.Directories}}): angi lagringsmapper via [[setting:files-directory]], [[setting:databases-directory]], [[setting:engines-directory]] og [[setting:puzzles-directory]].
- [[settings-category:repertoire]] ({{label:Settings.Repertoire}}): dekningsgrense for repertoar og treningsplanlegging via [[setting:repertoire-depth]], [[setting:practice-grading]] og [[setting:practice-new-per-session]].
- [[settings-category:coach]] ({{label:Settings.AI}}): administrer KI-tilkoblinger for Coach og Assistant, velg modellen de svarer med i [[setting:coach-model]], og velg lokal motor for Coach i [[setting:coach-engine]].
- [[settings-category:advanced]] ({{label:Settings.Advanced}}): vedlikeholdsverktøy inkludert [[setting:reload]], [[setting:clear-saved-data]] og [[setting:open-logs]].
