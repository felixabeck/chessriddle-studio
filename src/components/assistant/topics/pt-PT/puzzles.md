Para começar a resolver problemas, abra [[page:new-tab]] e clique em {{label:Home.Card.Puzzle.Title}}.

Quando o treino ChessRiddle estiver disponível, pode alternar entre {{label:Puzzle.Source.ChessRiddle}} e {{label:Puzzle.Source.Offline}} usando o seletor de fonte no topo do painel de problemas (ou clicar em {{label:Puzzle.Source.UseOffline}} para ir diretamente para os problemas offline).

**{{label:Puzzle.Source.ChessRiddle}}** requer uma conta ChessRiddle ligada (pode ligá-la diretamente a partir do painel de problemas ou em [[page:accounts]]):
- Alterne entre {{label:Training.Tactics}} e {{label:Training.Mistakes}} para treinar tática geral ou rever problemas falhados.
- Introduza os lances para ambos os lados no tabuleiro e depois submeta a sua linha.
- Clique em {{label:Training.Settings.Title}} para escolher {{label:Training.Settings.Difficulty}}, {{label:Training.Settings.Motif}}, {{label:Training.Settings.ShowSolutionLength}}, {{label:Training.Settings.ShowTimer}} e {{label:Training.Settings.TimerMode}}.
- Clique em {{label:Training.Shortcuts.Title}} (ou prima `?`) para ver os atalhos de teclado do treino.

**{{label:Puzzle.Source.Offline}}** usa bases de dados de problemas locais guardadas em [[setting:puzzles-directory]]:
- Abra a lista de bases de dados e escolha {{label:Common.AddNew}} para transferir uma base de problemas do catálogo ou clique em {{label:Puzzle.ChooseLocalFolder}} para escolher uma pasta local.
- Clique em {{label:SideBar.Settings}} (o ícone de engrenagem) para definir {{label:Puzzle.RatingRange}}, filtrar por {{label:Puzzle.Theme}} e ativar ou desativar {{label:Puzzle.Progressive}}, {{label:Puzzle.HideRating}}, {{label:Puzzle.JumpToNextPuzzleImmediately}} e {{label:Puzzle.TrackPuzzleTime}}.
- Remova a base de dados de problemas selecionada com {{label:Puzzle.DeleteDatabase}}.
